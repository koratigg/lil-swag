# WHILE
Цикл *while* (англ. *пока*) — это цикл, который выполняется пока условие истинно.

## Синтаксис:
``` 
while (условие) {  
    // Тело цикла  
}  
```

## Пример:

```
int i = 0;  
while (i < 5) {  
    std::cout << i << " ";  // Выведет: 0 1 2 3 4  
    i++;  
}  
```

## Особенности:
- Если условие ложно с самого начала, цикл не выполнится ни разу.

- Риск бесконечного цикла, если условие никогда не станет ложным.

# FOR
Цикл *for* -- это цикл с **предопределённым количеством итераций**, объединяющий инициализацию, условие и изменение счётчика.

## Синтаксис:
```
for (инициализация; условие; изменение) {  
    // Тело цикла  
}
```

## Пример:  
```
for (int i = 0; i < 5; i++) {  
    std::cout << i << " ";  // Выведет: 0 1 2 3 4  
}  
```

## Особенности:
- Удобен, когда известно точное количество итераций.

- Можно пропускать части (for (;;) — бесконечный цикл).

# DO WHILE
Цикл *do-while* — это разновидность **while**, которая гарантирует выполнение тела цикла хотя бы один раз, даже если условие ложно.

##  Синтаксис:
```
do {  
    // Тело цикла  
} while (условие);  // Обратите внимание на точку с запятой!  
```

##  Пример: Сумма чисел до 0
```
#include <iostream>
using namespace std;

int main() {
    int num, sum = 0;
    do {
        cout << "Введите число (0 для выхода): ";
        cin >> num;
        sum += num;
    } while (num != 0);

    cout << "Сумма: " << sum << endl;
    return 0;
}
```
##  Особенности :
- Тело выполнится хотя бы 1 раз, даже если условие ложно.  
- Область видимости переменных — переменные, объявленные внутри do { ... }, не видны в условии.  
- Не забывайте ; после while(условие)!
